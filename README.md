### Box 2

**Fault Observed:**
The CPU fan turns on and off repeatedly.

**Troubleshooting Steps:**
- Components were removed from the unit.
- Parts were exchanged with another box to see whether the fault followed the part.

**Outcome:**
Even after swapping parts, the fan and the rest of the unit still did not work properly.

**Conclusion:**
Since the swapped components did not fix the problem, the motherboard is the most likely cause.

Further testing is required to confirm this by:
- Testing the motherboard in a known-good setup.
- Testing a known-good motherboard in this unit.

## 3. Summary

- Two of the three keyboards (**Pink** and **Blue**) are fully functional.
- The **Green** keyboard works but is missing its **Esc key**.
- The Green keyboard needs a replacement keycap or should be marked as faulty.
- **Box 1** was brought to working order using the HDD and RAM extracted from another system unit.
- **Box 2** has an unresolved CPU fan fault.
- The **motherboard is the suspected cause** of the Box 2 fault.

## Conclusion

The hardware testing identified working and faulty components across the tested system units and keyboards.

**Box 1** was successfully brought to working order using replacement components, while **Box 2** requires further motherboard testing to confirm the suspected fault.

Of the three keyboards tested, **two are fully functional**, while **one requires attention due to a missing Esc key**.
